# Definition of Done

Sebuah tahap hanya dianggap selesai jika:

- Ruang lingkup prompt tahap telah terpenuhi.
- Tidak ada placeholder penting tanpa penjelasan.
- Migration berhasil.
- Seed berhasil bila relevan.
- Lint berhasil.
- Typecheck berhasil.
- Unit test berhasil.
- Integration test berhasil bila relevan.
- Build berhasil.
- Swagger diperbarui.
- Dokumentasi diperbarui.
- Tidak ada secret di repository.
- Risiko dan pekerjaan lanjutan dicatat.
- Perubahan dapat dijalankan ulang dari repository bersih.
