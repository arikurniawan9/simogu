# Tahap 11 — Notifikasi

Implementasikan notifikasi dalam aplikasi:

- Pengajuan baru untuk admin.
- Approval untuk petugas.
- Rejection untuk petugas.
- WhatsApp gagal.
- Jadwal bermasalah.
- Pengingat piket bila konfigurasi tersedia.

Fitur:

- Daftar notifikasi.
- Tandai dibaca.
- Tandai semua dibaca.
- Unread count.
- Deep link ke objek terkait.

Siapkan Firebase Cloud Messaging untuk Flutter.

Gunakan adapter sehingga notifikasi push dapat dimock saat test.

Tambahkan test hak akses dan delivery mock.
