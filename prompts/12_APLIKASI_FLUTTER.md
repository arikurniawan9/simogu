# Tahap 12 — Aplikasi Flutter Android dan iOS

Bangun aplikasi mobile menggunakan Flutter dan Riverpod.

Fitur:

- Login.
- Secure token storage.
- Refresh token.
- Jadwal hari ini.
- Cari guru.
- Detail jadwal.
- Catat absensi.
- Pilih beberapa jam.
- Ajukan perubahan.
- Upload bukti.
- Riwayat pengajuan.
- Notifikasi.
- Profil.
- Logout.

Kebutuhan:

- Environment dev, staging, production.
- Dio interceptor.
- Handling offline dan error.
- Loading, empty state, dan retry.
- Bahasa Indonesia.
- Desain responsif.
- Push notification FCM.
- Tidak menyimpan credential sensitif di source code.

Jalankan:

- flutter analyze
- flutter test
- build APK debug

Dokumentasikan build AAB dan iOS.
