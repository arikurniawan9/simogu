# Tahap 10 — Dashboard dan Laporan

Buat dashboard admin:

- Guru aktif
- Jadwal hari ini
- Tidak hadir hari ini
- Izin
- Sakit
- Tugas dinas
- Tanpa keterangan
- Pengajuan menunggu
- WhatsApp gagal

Buat grafik:

- Tren bulanan
- Status kehadiran
- Ketidakhadiran per hari
- Guru dengan ketidakhadiran terbanyak
- Kelas dengan jam kosong terbanyak

Buat laporan:

- Harian
- Mingguan
- Bulanan
- Semester
- Per guru
- Per kelas
- Per mata pelajaran
- Per status
- Change request
- WhatsApp

Ekspor:

- Excel
- PDF

Pastikan filter tervalidasi dan query efisien.
Tambahkan test perhitungan agregat dan ekspor.
