# Tahap 04 — Master Data Guru dan Kelas

Implementasikan CRUD:

- Guru
- Kelas
- Jam pelajaran
- Tahun ajaran
- Semester
- Hari libur sekolah

Guru wajib mendukung:

- Kode unik
- Nama
- Jenis kelamin
- Nomor WhatsApp
- Mata pelajaran
- Status aktif
- Soft delete
- Pencarian kode dan nama
- Pagination
- Sorting
- Filter

Normalisasi nomor Indonesia ke format 62.

Buat halaman admin responsif untuk seluruh master data.

Tambahkan:

- Validasi frontend dan backend.
- Audit log.
- Swagger.
- Unit dan integration test.
- Konfirmasi sebelum menonaktifkan data.
- Larangan hard delete data historis.

Jangan membuat jadwal.
