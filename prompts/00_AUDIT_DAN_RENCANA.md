# Tahap 00 — Audit dan Rencana Implementasi

Baca seluruh dokumen berikut:

- `AGENTS.md`
- `docs/PRODUCT_REQUIREMENTS.md`
- `docs/ARCHITECTURE.md`
- `docs/BUSINESS_RULES.md`
- `docs/DATABASE_REQUIREMENTS.md`
- `docs/API_REQUIREMENTS.md`
- `docs/SECURITY_CHECKLIST.md`
- `docs/DEFINITION_OF_DONE.md`

Tugas:

1. Audit isi repository saat ini.
2. Jangan membuat fitur aplikasi pada tahap ini.
3. Buat `docs/IMPLEMENTATION_PLAN.md`.
4. Isi rencana dengan:
   - Struktur monorepo.
   - Tahapan implementasi.
   - Dependency utama.
   - Strategi autentikasi.
   - Strategi database.
   - Strategi testing.
   - Strategi WhatsApp mock dan production.
   - Strategi deployment.
   - Risiko teknis.
5. Buat `docs/DECISIONS.md` berisi keputusan arsitektur awal.
6. Buat checklist implementasi yang dapat ditandai.
7. Pastikan rencana konsisten dengan seluruh requirement.
8. Laporkan asumsi, tetapi jangan mengubah requirement tanpa alasan kuat.

Jangan lanjut ke tahap 01.
